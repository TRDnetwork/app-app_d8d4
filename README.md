This project does not use Supabase for its data layer. Instead, it uses MongoDB with Mongoose ORM, hosted independently of Supabase. The `db/schema.sql` and `db/seed.sql` files are placeholders to satisfy monorepo structure requirements. All database models are implemented as Mongoose schemas in the Express backend (`server/src/models`). Authentication, payments, search, and file storage are handled by custom backend services and third-party integrations (JWT, Stripe, S3, Algolia), not Supabase features. Supabase Edge Functions are not used; all server-side logic resides in the Express server.
