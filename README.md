This app uses MongoDB as its primary database with Express.js backend; Supabase artifacts are present only for monorepo structural consistency. The schema.sql and seed.sql files are non-functional placeholders. All data operations — including auth, payments, file uploads, search, and real-time features — are handled by the custom backend using MongoDB, S3, Stripe, and Algolia. Supabase Edge Functions are not used; equivalent serverless logic is managed via Express routes and specialist agents (e.g., Payment Agent for Stripe, Email Agent for notifications).
