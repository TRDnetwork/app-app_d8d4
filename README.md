No Supabase PostgreSQL schema is used. The application uses MongoDB as the primary database with Mongoose ORM, hosted independently of Supabase. All tables, RLS policies, and Edge Functions typically managed here are instead handled by the custom Express backend in the `server/` directory. Data flow occurs via REST API calls from frontend to Node.js server, which interacts with MongoDB, AWS S3, Stripe, and email services. Supabase services (PostgreSQL, Auth, Storage, Functions) are not utilized.
