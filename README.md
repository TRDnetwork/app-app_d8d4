This schema defines the MongoDB data model for ShopSphere, a full-featured e-commerce platform. It includes 10 collections prefixed with `app_d8d4_`: users, addresses, products, categories, reviews, orders, cart, wishlist, coupons, questions, and seller analytics. Each model enforces data integrity via Mongoose validation, indexes for query performance, and role-based access patterns. The seed script populates sample admin, seller, customer, categories, and products for testing. This backend supports JWT auth, Stripe payments, AWS S3 image storage, and RBAC for customer/seller/admin roles. No Supabase components are used — backend is Express + MongoDB.
